# ISOs privadas de teste

Coloque aqui imagens fornecidas legalmente para os testes. O manifesto
[`../corpus-manifest.json`](../corpus-manifest.json) registra nomes originais,
tamanhos, SHA-256 e caminhos relativos ao checkout; não contém os jogos.

Os arquivos deste diretório são ignorados pelo Git, exceto este README.
Um clone no Cloud não recebe as ISOs nem os insumos existentes no PC original.
Não renomear imagens para ocultar o conteúdo ou contornar uma recusa.

Consulte [`../../docs/CODEX_CLOUD.md`](../../docs/CODEX_CLOUD.md).
